# Governance

Octopus is intended to remain fully open source.

## Maintainers

Maintainers are responsible for project direction, release quality, safety review, and community standards.

Initial maintainer:

- BenchBrex

## Decision principles

Project decisions should prioritize:

1. User safety
2. Privacy
3. Explainability
4. Self-hostability
5. Community benefit
6. Long-term maintainability

## Licensing

Octopus uses AGPL-3.0-or-later to protect the public-good nature of the project, including hosted versions.

## Rule changes

Changes to financial risk rules must include:

- A clear explanation
- Test cases
- Known limitations
- User-facing wording

## AI-related changes

AI features must remain optional. Core safety flows should work without an AI provider.

Any AI output must be presented as support, not as final authority.
